# dsh-my-prompt-polish

中文 | [English](./README.md)

在 DeepSeek Harness（DSH）的输入框旁边加一个润色按钮。

点一下，输入框里的文字会被模型改写，用的是**你在设置里自己写的那条规则**。再点一下，草稿原样退回你打的样子。**不会发送**：按钮只改草稿，回车还是你自己按。

## 它做什么

1. **一个按钮，四种状态。** 平时是个星芒图标；改写成功后变成回退图标，点一下还原原文；请求进行中是转圈；出错是警告图标，原因在悬停提示里。
2. **用你的规则，不用预设。** 设置 → 提示词优化 里有一个文本框，放着基准提示词。每次调用都拿它当系统提示词。旁边有「恢复默认规则」，可以把内置的那套四条中文改写规则放回去。
3. **用你选的模型，不写死。** 模型下拉里可以选「跟随当前会话模型」（默认），也可以指定任何已配置的通道和模型。插件**不要自己的 API Key**，直接用你在 DSH 里配好的。
4. **不会把你的活弄丢。** 请求期间草稿变了，它不替换；草稿里有 `@` 引用，它拒绝改（整段替换会把引用弄没）；改写之后你又编辑过，它就不再把「原文」盖回来。

## 安装

从 GitHub 装：

```sh
dsh plugin --profile web add github:LianYuyuyuyuyu/dsh-my-prompt-polish
```

（`web` 是默认 profile 名；宿主用的不是这个名字就换成实际的。）装完重启宿主。

或者：在 **插件 → 发现 → 索引源** 里加上本仓库的 `index.json`，就能在列表里一键装。

## 怎么用

1. 在输入框里打点内容。
2. 点星芒图标。
3. 草稿被换成改写后的版本。想退回就点回退图标。

设置项在 **设置 → 提示词优化**：基准提示词、用哪个模型，以及插件写的两个文件路径。

## 它会写哪些文件

- `$DSH_HOME/prompt-polish/rule.md` —— 你的基准提示词（`$DSH_HOME` 默认是 `~/.dsh`）。
- `$DSH_HOME/prompt-polish/config.json` —— 选定的通道和模型。

都是本机、按用户存的。删掉就回到默认。

## 要求

- DSH `>= 0.2.2-rc.1`。它要用 `conversation.input.left` 和 `settings.section` 两个插槽，以及 `llm`、`webServer` 两个服务。
- DSH 里已经配好至少一个模型。插件自己没有任何凭据。

## 说清楚的局限

- 改写就是一次模型调用，要花 token，快慢取决于你的模型。
- 按钮替换的是**整段草稿**。所以草稿里有 `@` 引用或图片时它不干。
- 大多数改写都是整段重写，很短的话通常会被写长。这是它的用途，但不总是你想要的。
